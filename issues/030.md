## E-1. 보스방 배치

- [ ] 보스 스폰 위치 설정
- [ ] 플레이어 진입 트리거 배치

## 스모크 테스트 (Day 4 마무리)

> 정식 테스트는 Day 5이지만, **사이클이 한 번이라도 도는지** 반드시 확인 후 마무리.

- [ ] 에디터에서 시작 → 보스방 진입 → 보스 처치 → 아이템 획득 → 클리어 화면까지 **1회 통과 확인**
- [ ] 통과 못 하면 즉시 막힌 지점만 픽스하고 다시 1회 통과까지 확인
- [ ] 발견된 버그는 메모만 남기고 수정은 Day 5에 (단, 진행 불가 버그는 오늘 해결)
