## 버그 요약

`PlayerJump.cs`의 플랫폼 통과 로직(`Physics2D.IgnoreLayerCollision`)에서 두 가지 버그 발생.

---

## Bug 1 — 머리 위 플랫폼 통과 불가

### 현상
플레이어 바로 머리 위에 플랫폼이 있을 때 점프하면 통과하지 못하고 막힘.

### 원인
`PlayerMotor`와 `PlayerJump`의 `FixedUpdate` 실행 순서 불일치.

```
PlayerJump.FixedUpdate:
1. motor.SetVelocityY(jumpSpeed)  → requestedY에 저장만 됨 (rb에 미적용)
2. motor.VelocityY 읽기           → rb.linearVelocityY = 0 (PlayerMotor 미실행)
3. isRising = 0f > 0.1f = false
4. IgnoreLayerCollision = false   ← 충돌 켜진 채로!
5. PlayerMotor.FixedUpdate에서야 rb.velocity = jumpSpeed 적용
   → 이미 플랫폼과 충돌 결정됨
```

---

## Bug 2 — 플랫폼 중간에서 점프컷 시 끼임 (더 심각)

### 현상
플랫폼을 통과하는 도중 점프 버튼을 떼면 플레이어가 플랫폼 내부에 끼어버림.

### 원인
점프컷으로 `VelocityY`가 `0.1f` 아래로 떨어지는 순간 `IgnoreLayerCollision = false`가 되는데, 이때 플레이어 콜라이더가 아직 플랫폼 내부에 있으면 Unity 물리 충돌 해소(depenetration)가 발생해 끼임.

---

## 수정 방법

**`Assets/Scripts/Player/PlayerJump.cs` 수정**

### 수정 1 — `justJumped` 플래그 (Bug 1)
`doJump`를 소모하기 전에 캡처해 `isRising` 판단에 포함.  
`PlayerMotor`가 velocity를 아직 적용하기 전인 프레임도 "상승 중"으로 처리.

```csharp
bool justJumped = doJump;
if (doJump)
{
    motor.SetVelocityY(jumpSpeed);
    OnJumped?.Invoke();
    doJump = false;
}
// ...
bool isRising = motor.VelocityY > 0.1f || justJumped;
```

### 수정 2 — `IsInsidePlatform()` 체크 (Bug 2)
속도가 떨어져도 플레이어가 플랫폼 내부에 있는 동안은 통과 상태(`inPassthrough`) 유지.

```csharp
if (isRising)
{
    inPassthrough = true;
}
else if (inPassthrough)
{
    bool stillInside = playerCollider.OverlapCollider(platformFilter, overlapBuffer) > 0;
    if (!stillInside)
        inPassthrough = false;
}

if (groundDetector.IsGrounded)
    inPassthrough = false;

Physics2D.IgnoreLayerCollision(playerLayerIndex, ceilingLayerIndex, inPassthrough);
```
