## 개요
보스 Phase 1에서 사용하는 전투 패턴 2종(직선 돌진, 발사체)과 패턴 선택 로직을 구현한다.

---

## C-1. 패턴 1: 직선 돌진

- [ ] 플레이어 방향 락온
- [ ] 텔레그래프 0.5초 (색 변경으로 표현)
- [ ] 빠르게 돌진 → 벽 또는 시간 도달 시 정지
- [ ] 쿨다운 처리

## C-2. 패턴 2: 발사체

- [ ] `BossProjectile.cs` (직선 이동 + 플레이어 충돌 시 데미지)
- [ ] **오브젝트 풀링** 적용 (`ProjectilePool.cs`)
  - 리스크: 막히면 일단 `Instantiate/Destroy`로 동작시키고 다음 주 리팩토링
- [ ] Phase1State에서 3발 부채꼴 or 직선 발사

## C-3. 패턴 선택 로직

- [ ] Phase1State 내부에서 쿨다운마다 패턴 1/2 랜덤 or 순차 선택
- [ ] 패턴 간 최소 간격 1~2초

## C-4. 보스 피격

- [ ] 플레이어 공격 → 보스 HP 감소
- [ ] 피격 시 짧은 무적 프레임 + 색 플래시
