## 개요

플레이어 애니메이션 시스템을 활성화하고, 기존에 로직만 구현되어 있던 3콤보 공격에 애니메이션을 연결한다.  
대시 기능도 새로 추가한다.

## 작업 범위

### 1. PlayerAnimator 활성화
- 이동(SpeedX), 수직 속도(VerticalVelocity), 착지(IsGrounded), 점프(Jump) 파라미터 갱신
- 이동 입력 기준 SpriteRenderer flip 처리
- 변신(Human/Dog/Cat) 시 RuntimeAnimatorController 교체

### 2. 콤보 공격 애니메이션 연결
- `PlayerAttack.ExecuteAttack()`에서 `PlayerAnimator.PlayAttack(comboIndex)` 호출
- Animator 트리거: `Attack1`, `Attack2`, `Attack3`

### 3. 대시 구현
- `PlayerDash` 컴포넌트 신규 추가
- 입력: 별도 대시 키 (InputAction 추가)
- 쿨다운 및 무적 프레임 옵션
- Animator 트리거: `Dash`

## Animator Controller 파라미터 목록

| 이름 | 타입 | 설명 |
|---|---|---|
| SpeedX | Float | 수평 이동 속도 절댓값 |
| VerticalVelocity | Float | 수직 속도 (점프/낙하 구분) |
| IsGrounded | Bool | 착지 여부 |
| Jump | Trigger | 점프 시작 |
| Attack1 | Trigger | 1번째 콤보 |
| Attack2 | Trigger | 2번째 콤보 |
| Attack3 | Trigger | 3번째 콤보 |
| Dash | Trigger | 대시 |
