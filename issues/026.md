## 개요
아이템 ScriptableObject 정의부터 HUD 표시, 스테이지 클리어 시퀀스까지 아이템 획득 파이프라인 전체를 구현한다.

---

## A-1. 아이템 ScriptableObject 정의

- [ ] `ItemData.cs` ScriptableObject 생성
  - 필드: `id`, `displayName`, `icon`, `isStageClearTrigger` (bool)
- [ ] 테스트용 "Stage Key" 에셋 1개 생성

## A-2. 아이템 픽업 시스템

- [ ] `ItemPickup.cs` (Trigger Collider2D)
  - `ItemData` 참조 필드
  - `OnTriggerEnter2D`로 플레이어 감지 → 이벤트 발행 후 자기 자신 Destroy
- [ ] 아이템 획득 이벤트 채널 (`ItemPickedUpEvent` — C# event 또는 SO 채널)

## A-3. HUD 아이템 슬롯

- [ ] HUD에 아이템 아이콘 슬롯 1~2개 추가 (기존 HUD 있으면 확장)
- [ ] 이벤트 구독 → 아이콘 활성화

## A-4. 스테이지 클리어 매니저

- [ ] `StageClearManager.cs` (씬 단위 싱글톤 or 일반 매니저)
- [ ] `isStageClearTrigger == true` 아이템 획득 시 → 클리어 시퀀스 실행
- [ ] 클리어 시퀀스: 입력 차단 → 페이드아웃 → "Stage Clear" 텍스트 → (다음 씬 로드 or 타이틀 복귀)
- [ ] 임시로 페이드는 검은색 Image의 alpha 트윈으로 처리
