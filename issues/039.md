## 본문

## 버그 요약

`PlayerGroundDetector.cs`가 `OverlapBox` 기반 감지를 사용하는 상태에서, 플레이어가 일방통행 플랫폼을 **아래에서 위로 통과하는 중** `IsGrounded = true`로 오탐되어 이중 점프가 발동되는 버그.

---

## 현상

- 플랫폼을 아래에서 통과 도중 점프 버튼을 누르면 이중 점프 발동
- Platform Effector 2D로 충돌이 억제된 플랫폼을 바닥으로 잘못 인식

## 원인

`OverlapBox`는 Platform Effector 2D가 충돌을 억제(suppress)했는지 알 수 없음.  
Effector가 억제한 충돌은 `Collision2D.enabled = false`로 표시되므로, 이를 걸러내는 로직이 필요.

```csharp
// OverlapBox 방식은 충돌 억제 여부를 알 수 없음
Vector2 boxSize = new Vector2(col.size.x, groundCheckRadius * 2f);
IsGrounded = Physics2D.OverlapBox(groundCheck.position, boxSize, 0f, groundLayer);
```

## 수정

`OnCollisionEnter2D` / `OnCollisionStay2D` 이벤트 기반 감지로 교체.  
`Collision2D.enabled == false`인 contact(Effector가 억제한 충돌)는 바닥 접촉으로 인정하지 않음.

```csharp
private void EvaluateContact(Collision2D other)
{
    if (!other.enabled) return;  // Effector 억제 충돌 제외
    if (((1 << other.gameObject.layer) & groundLayer) == 0) return;
    foreach (var contact in other.contacts)
    {
        if (contact.normal.y > 0.7f)
        {
            groundedThisStep = true;
            return;
        }
    }
}
```
