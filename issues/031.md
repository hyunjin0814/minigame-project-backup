## 개요
Day 5 전일 작업. 전체 사이클 플레이 테스트 → 버그 목록화 → 수정 → PC 빌드 산출.

---

## E-2. 플레이 테스트

- [ ] 전체 사이클 **3회 이상** 반복 테스트
  - 시작 → 일반 적 처치 → 보스방 진입 → 보스전 → 처치 → 아이템 획득 → 클리어 화면
- [ ] 변신(인간 / 개 / 카멜레온) 모두 보스전에서 사용 가능한지 확인
- [ ] 사망 시 재시작 / 타이틀 복귀 동작 확인
- [ ] 발견된 버그 목록화 (우선순위 매기기)

## E-3. 버그 수정 + 빌드

- [ ] **크리티컬 버그 우선 수정** (크래시, 진행 불가)
- [ ] 시간 남으면 마이너 버그 수정
- [ ] PC 빌드 산출 → 압축 → 산출물 폴더에 저장
- [ ] 빌드본으로 최종 사이클 **1회 확인**

---

## 빌드 성공 기준 (Week 1 최종)

- [ ] 플레이어가 일반 적과 전투 가능
- [ ] 보스방 진입 → 보스전 → 보스 처치 가능
- [ ] 보스 처치 시 아이템 드롭
- [ ] 아이템 획득 시 스테이지 클리어 처리 (페이드 + 텍스트 or 다음 씬)
- [ ] 전체 사이클 크래시 없이 동작

---

## 비상 플랜
- 크리티컬 버그 해결이 어려우면 보스 HP를 낮춰서라도 클리어 가능한 상태로 빌드 산출
