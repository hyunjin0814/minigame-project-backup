## 개요

GDD 기준으로 미구현된 적 AI 시스템을 추가 구현한다.  
Patrol → Chase → Attack 단순 구조에서 Alert / Search / Chase 하이브리드 / Attack 원형 감지까지 확장한다.

---

## 작업 항목

### 1. `EnemyController.cs` — Alert / Search / Chase 하이브리드 / Attack 원형 감지 ✅
- **Alert**: 감지 시 1초 대기 → 확장 시야(×1.4)로 재확인 → Chase or Patrol 복귀
- **Search**: 플레이어를 놓치면 마지막 목격 위치 이동 → 도착 후 3초 두리번 → Patrol
  - 도착 전에는 타이머 카운트 안 함 (이동 시간 제외)
  - 두리번 중 재감지 → Alert (Chase 직행 아님)
- **Chase 하이브리드**: 원형(7u) 안이면 동적 추적 / 밖이면 lastSeenPosition 돌진
  - 벽·절벽에 막히거나 목적지 도착 시 Search 전환
  - 수직 높이 초과(기본 2u) + 원형 범위 밖 → Search 전환 (범위 안이면 유지)
- **Attack 원형 감지(9u) + 히스테리시스**:
  - 원형 안: lastSeenPosition 갱신
  - 원형 밖: grace timer(1.5s) 누적 → 만료 시 Search
  - 사거리 안: 공격 (windup 0.5s) / 사거리 밖 + 원형 안: 추격 이동
- `ReactToHit()`: Patrol 상태에서 피격 시 즉시 Chase 전환

### 2. `EnemySight.cs` — Alert 확장 시야 지원 ✅
- `CanSeePlayer(float radiusMultiplier)` 오버로드 추가
- 원형 감지용 `IsPlayerInCircle(float radius)` 추가
- 원거리 적 Obstacle Layer 누락 수정

### 3. `EnemyMovement.cs` — Search 이동 지원 ✅
- `AlertTick()` / `ApplyAlertVelocity()` (Alert 정지 처리)
- `SearchTick(Vector2 target)` / `ApplySearchVelocity()` (목적지 이동 + 두리번)
- `ArrivedAtSearch` 프로퍼티 (타이머 카운트 조건)
- `ArrivedAtChaseTarget()` / `IsBlockedToward()` (Chase lunge 포기 판정)

### 4. `SightConeRenderer.cs` (신규) — 인게임 시야 콘 시각화 ✅
- MeshFilter + MeshRenderer로 부채꼴 메시 동적 생성
- 상태별 5단계 색상: Patrol=회색, Alert=노랑, Chase=주황, Attack=빨강, Search=파랑
- 상태별 형태 전환: Patrol/Alert=시야 콘, Chase/Attack/Search=원형 메시
- FacingDirection 변경 시 실시간 방향 업데이트

### 5. `ChameleonStealth.cs` — 3단계 감지 모디파이어 ❌ (미구현, 이후 작업)
- `HiddenStealth` (정지): alpha 0.05, 감지 반경 ×0.4
- `MovingStealth` (이동 중): alpha 0.5, 감지 반경 ×0.6
- `Visible` (노출): alpha 1.0, 감지 반경 ×1.0
- 점프 중 전 형태 modifier 1.0 강제 적용

### 6. `AttackHitbox.cs` — 후방 기습 데미지 ❌ (미구현, 이후 작업)
- Patrol 상태 적 후방 공격 → 데미지 ×3
