## 본문

## 문제

`PlayerHorizontalMovement`와 `PlayerJump`가 각각 `rb.linearVelocity` 에 값을 할당하는 문제 있음.

```csharp
// PlayerHorizontalMovement.FixedUpdate — X만 바꾸려는 의도지만 전체 Vector2를 씀
rb.linearVelocity = new Vector2(rb.linearVelocity.x + movement, rb.linearVelocity.y);

// PlayerJump.Update — Y만 바꾸려는 의도지만 전체 Vector2를 씀
rb.linearVelocity = new Vector2(rb.linearVelocity.x, jumpSpeed);
```

두 스크립트가 서로 다른 루프(`FixedUpdate` vs `Update`)에서 실행되어 실행 순서 의존성이 생기며, 스크립트 추가/순서 변경 시 한 축의 변경값이 조용히 덮어써질 수 있음.

또한 대시, 넉백 등 이동 관련 기능이 추가될수록 충돌 위험이 커지는 구조적 문제가 있음.

## 해결 방안

`PlayerMotor` 컴포넌트를 도입하여 `Rigidbody2D` 조작을 한 곳에서 전담.

각 이동 스크립트는 원하는 속도값만 `PlayerMotor`에 전달하고, `PlayerMotor`가 매 `FixedUpdate`에 한 번만 `linearVelocity`를 적용.

```
PlayerHorizontalMovement  ─┐
PlayerJump                 ├─→  PlayerMotor  →  Rigidbody2D
(미래) Dash, Knockback...  ┘
```
