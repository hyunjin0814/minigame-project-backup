# 맵 로드 시스템

## 배경
비밀방 시스템 완료 이후, 메트로배니아 핵심 골격인 **4구역 씬 구조 + 진행 상태 유지 + 잠금 구역 + 체크포인트**를 구현한다.  
현재는 `TestScene.unity` 단일 씬으로 동작하고 있으며, GDD의 구역 간 이동·백트래킹·능력 해금 플로우가 전혀 연결되지 않은 상태다.

---

## 구현 범위

### 1. `GameState.cs` — 전역 진행 상태 관리

`DontDestroyOnLoad` 싱글톤으로 씬 전환 사이에서도 상태를 유지한다.

```csharp
// 능력 해금
public bool dashUnlocked;
public bool catUnlocked;
public bool dogUnlocked;

// 월드 상태
public HashSet<string> openedDoors;    // 열린 잠금 구역 ID
public HashSet<string> collectedItems; // 수집 아이템 ID

// 체크포인트
public string lastCheckpointID;
public Vector2 spawnPosition;

// 현재 HP (씬 복원용)
public int currentHP;
```

- `SaveCheckpoint(string id, Vector2 pos)` 메서드 제공
- 씬 전환 후 `spawnPosition`으로 플레이어 위치 복원 처리

---

### 2. `LockedDoor.cs` — 잠금 구역 3종

| 잠금 타입 | 해금 조건 | 구역 |
|-----------|-----------|------|
| `DashGap` | `GameState.dashUnlocked == true` | 구역A → 구역B |
| `NarrowPassage` | `GameState.catUnlocked == true` | 구역B → 구역C |
| `BossDoor` | 중간보스 클리어 (`openedDoors` 포함 여부) | 구역C → 구역D |

- 잠금 상태일 때 시각적 피드백 표시 (스프라이트 또는 파티클)
- 해금 조건 충족 시 자동으로 열림 (애니메이션 or 비활성화)

---

### 3. `Checkpoint.cs` — 체크포인트

- 각 구역 입구 4곳에 배치
- 플레이어 접촉 시:
  - `GameState.SaveCheckpoint()` 호출
  - HP 전체 회복
  - 활성화 이펙트 표시 (한 번만)
- `GameOverManager` 수정: 씬 리로드 → 마지막 체크포인트로 복귀

---

### 4. 씬 전환 — `ZoneTransition.cs`

GDD 씬 구성:

```
ZoneA_Ruins.unity
ZoneB_CentralHall.unity
ZoneC_Underground.unity
ZoneD_BossArea.unity
```

- 구역 경계 트리거에서 `LoadSceneAsync` + 페이드 인/아웃
- 씬 전환 시 `GameState`의 `spawnPosition`으로 플레이어 위치 설정
- 페이드 연출: `CanvasGroup.alpha` 코루틴 (0→1→0)

---

### 5. 씬 구조 재구성

- `TestScene.unity`를 기반으로 위 4개 씬 분리 및 최소 레이아웃 배치
- 각 씬에 체크포인트 오브젝트 1개 이상 배치
- 구역 경계마다 `LockedDoor` + `ZoneTransition` 트리거 배치
