## 개요
메트로배니아 능력 순차 해금 시스템을 구현합니다.
플레이어가 특정 아이템을 획득하면 새 변신 능력이 해금되고, 그에 맞는 LockedDoor가 열립니다.

## 작업 범위

### 1. `AbilityUnlockItemData.cs` 신규 구현
- `InstantItemData` 상속
- `AbilityType` 필드 (Dash / Cat / Dog)
- `ApplyEffect()` → `GameState.UnlockDash/Cat/Dog()` 호출
- `GameState.collectedItems`로 중복 획득 방지

### 2. `PlayerTransformController.cs` 수정
- 변신 시도 시 `GameState.catUnlocked` / `dogUnlocked` 체크
- 잠긴 형태로 변신 시도 시 UI 피드백 (예: 화면 메시지 또는 이펙트)

### 3. 맵 배치
- 각 구역 탐험 경로에 `ItemPickup` 프리팹 배치
- `LockedDoor` 오브젝트 적절한 위치에 배치
- 능력 해금 순서: 대시 → 고양이 → 강아지
