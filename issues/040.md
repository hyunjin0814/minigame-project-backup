## 본문

## 버그 요약

`EnemyController.ReactToHit()`이 `Patrol` 상태일 때만 Chase 전환을 처리해, **Alert / Search** 상태에서 피격 시 아무 반응이 없는 버그.

---

## 현상

- 적이 Alert(경계) 또는 Search(수색) 상태일 때 플레이어 공격에 맞아도 Chase로 전환되지 않음
- 피격 방향으로 고개를 돌리기만 하고 추격 없이 현재 상태 유지

## 원인

```csharp
// 기존 — Patrol만 체크
public void ReactToHit(Vector2 sourcePosition)
{
    movement.Flip(sourcePosition.x > transform.position.x ? 1 : -1);
    if (state == EnemyState.Patrol)
        ChangeState(EnemyState.Chase);
}
```

Alert/Search 상태는 이미 플레이어를 인지한 상태이므로, 피격 시 즉시 Chase로 전환해야 함.

## 수정

조건에 `Alert`, `Search` 추가. 공격자 위치를 `lastSeenPosition`으로 설정하여 Chase 시작점도 보정.

```csharp
public void ReactToHit(Vector2 sourcePosition)
{
    movement.Flip(sourcePosition.x > transform.position.x ? 1 : -1);
    if (state == EnemyState.Patrol || state == EnemyState.Alert || state == EnemyState.Search)
    {
        lastSeenPosition = sourcePosition;
        ChangeState(EnemyState.Chase);
    }
}
```
