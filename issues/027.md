## 개요
1페이즈만 채우되 다페이즈 확장이 가능한 보스 FSM 골격을 구현한다.

---

## B-1. 보스 FSM 골격

- [ ] `BossStateBase.cs` 추상 클래스 (`Enter`, `Update`, `Exit`)
- [ ] `BossStateMachine.cs` (현재 상태 보관, 전환 처리)
- [ ] `BossController.cs` (HP, Rigidbody2D, FSM 보유)

## B-2. 상태 클래스 4종

- [ ] `BossIntroState.cs` — 등장 시 1초 대기 (나중에 컷씬 자리)
- [ ] `BossPhase1State.cs` — **오늘 내용 채울 유일한 상태**
- [ ] `BossPhase2State.cs` — **빈 클래스만 생성** (다음 주 작업)
- [ ] `BossDeathState.cs` — 사망 연출 + 아이템 드롭

## B-3. 페이즈 전환 조건

- [ ] HP <= 50% → Phase2 전환 로직 작성
  - Phase2 콘텐츠가 없으므로 최대 HP를 Phase1만으로 처치 가능하게 조정 (예: HP 100, Phase2 진입 조건을 사실상 HP <= 0으로 설정)
- [ ] HP <= 0 → `DeathState` 전환
