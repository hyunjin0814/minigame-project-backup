## 본문

## 버그 요약

`PlayerGroundDetector.cs`의 `Physics2D.OverlapCircle`이 플레이어 중앙 기준 원형 감지를 사용해, 플레이어가 플랫폼 끝에 걸쳐 있을 때 바닥을 인식하지 못하는 문제 발생.

---

## 현상

- 플레이어가 플랫폼 가장자리에 걸쳐 있을 때 `IsGrounded = false`로 오탐
- 결과적으로 공중 상태로 취급되어 점프가 불가능하거나 이중 점프가 발동

## 원인

`OverlapCircle`은 groundCheck 위치(중앙) 기준 원형 감지이므로 콜라이더 너비 전체를 커버하지 못함.
플레이어 `BoxCollider2D`의 왼쪽/오른쪽 끝이 플랫폼에 걸쳐 있는 경우 감지 실패.

```csharp
// 기존 — 중앙 원형 감지
IsGrounded = Physics2D.OverlapCircle(groundCheck.position, groundCheckRadius, groundLayer);
```

## 수정

`BoxCollider2D` 너비 전체를 커버하는 `OverlapBox`로 교체.

```csharp
Vector2 boxSize = new Vector2(col.size.x, groundCheckRadius * 2f);
IsGrounded = Physics2D.OverlapBox(groundCheck.position, boxSize, 0f, groundLayer);
```
